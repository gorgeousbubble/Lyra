# PCB

**本目录暂时是空的 —— 还没有 PCB 文件。**

不是工具限制，是顺序问题：PCB 要等原理图定稿，原理图要等 [`../watch/design.md`](../watch/design.md)
末段的 5 项决策拍板。

## 前置条件

| # | 决策 | 为什么阻塞 PCB |
| --- | --- | --- |
| 1 | MCU 封装 | 决定焊盘、板子最小尺寸、层数。144-LQFP 是 20×20 mm，装不进手表 |
| 2 | 存储：保留 W25Q80 还是用片内 FlexNVM | 差一颗芯片和 4 根走线 |
| 3 | OLED：成品模块还是裸屏 + FPC 座 | 裸屏要自己做 SSD1306 电荷泵，多出一组元件和一块布局区域 |
| 4 | 提醒：蜂鸣器还是振动马达 | 马达要驱动管 + 续流二极管，且占用机械空间 |
| 5 | 续航目标 | 决定电池容量 → 决定板子面积和形状 |

## 之后的路径

1. 决策定稿 → 出 KiCad 原理图（符号、网络、netlist、BOM）
2. 定板型与层叠 → 元件布局
3. 布线：电源和模拟部分（MAX30102 的 LED 驱动、电池分压）需要人工介入，
   数字部分可以先跑自动布线再手工收拾

剥离彩屏之后**没有高速并口了**（原来 FlexBus 29 根信号跑 25 MHz），
剩下的都是 I2C / SPI / GPIO 低速信号，布线难度大幅下降。这是删掉彩屏的一个额外收益。
